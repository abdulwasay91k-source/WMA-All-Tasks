CSS Box Model Documentation

Introduction

CSS Box Model consists of Content, Padding, Border and Margin.

1. Content

Content is the actual text or information inside the box.

2. Padding

Padding is the space between content and border.

3. Border

Border is the line surrounding the content and padding.

4. Margin

Margin is the space outside the border.

5. Height and Width

I used different Height and Width values to observe changes in box size.

Conclusion

I learned how Content, Padding, Border and Margin affect the total size of an element.
